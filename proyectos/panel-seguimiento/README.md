# Panel de Seguimiento Comercial y Marketing

Reúne metas, reportes del equipo y actividad de marketing para localizar dónde se pierde el avance entre el primer contacto y la firma.

Creada por Alexis Rodríguez, Analista TI en Grupo Tierras de Chile.

## Recorrido

1. Selecciona el período y compara los resultados del embudo con las metas del equipo.
2. Entra al reporte de una ejecutiva y revisa sus contactos, visitas y reservas por proyecto.
3. Cruza las agendas con los datos de captación y consulta las firmas y ventas administrativas.

El panel permite relacionar el gasto en captación con las visitas y los resultados que reporta el equipo.

## Probar la demo

1. [Descarga el ZIP](https://github.com/Elgortax/terreno-ops/releases/download/v3.0.0/panel-seguimiento.zip) y extrae todos sus archivos.
2. Abre **Abrir demo.cmd**. Windows de 64 bits. El ZIP incluye Node.js.
3. Consulta **Cómo funciona.html** para el recorrido completo.

Los reportes, contactos, agendas y ventas son ejemplos generados para noviembre de 2026 y los períodos de comparación.
